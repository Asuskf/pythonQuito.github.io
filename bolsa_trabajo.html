vacante_01 · docencia_universitaria

Docente Tiempo Completo — Programación I y Programación II

  • Tiempo completo
  • Python
  • POO
  • Django
  • Odoo
  • Quito

Lidera las cátedras de Programación I y Programación II con Python como lenguaje eje: desde fundamentos y lógica hasta programación orientada a objetos, desarrollo web con Django y desarrollo sobre Odoo. Buscamos a alguien que haya escrito código en producción y sepa traducir esa experiencia a un aula.

lo que harás

  • Impartir Programación I: fundamentos, lógica, estructuras de control y estructuras de datos con Python.
  • Impartir Programación II: programación orientada a objetos, patrones básicos, buenas prácticas y control de versiones con Git.
  • Dictar módulos de desarrollo web con Django: ORM, vistas, plantillas, autenticación y APIs REST.
  • Dictar módulos de desarrollo sobre Odoo: modelos, vistas XML, módulos personalizados y lógica de negocio.
  • Diseñar y actualizar sílabos, prácticas de laboratorio y proyectos integradores evaluables.
  • Acompañar proyectos de titulación y semilleros de investigación aplicada.
  • Vincular a los estudiantes con la comunidad y la industria: eventos, retos y código abierto.

lo que buscamos

  • Título de tercer nivel en Sistemas, Software, Computación, Electrónica o afines.
  • Maestría afín (o en curso avanzado), valorada para la carga académica de tiempo completo.
  • Dominio sólido de Python y de programación orientada a objetos.
  • Experiencia práctica en Django y en Odoo: implementación o desarrollo de módulos.
  • Manejo de Git/GitHub, bases de datos relacionales (PostgreSQL/MySQL) y entornos Linux.
  • Experiencia docente o de capacitación técnica, formal o en comunidad y bootcamps.

Suma puntos si además…

Tienes proyectos publicados en GitHub, contribuciones a código abierto, experiencia con Docker o CI/CD, FastAPI, análisis de datos, o has dado charlas y talleres técnicos. Aquí el portafolio pesa tanto como el título.

vacante_02 · matemáticas_computacionales

Docente de Matemáticas con Programación Aplicada

  • Plus metodológico
  • Cálculo · Álgebra
  • Python
  • NumPy · SymPy
  • Jupyter
  • Quito

Enseña matemáticas usando la programación como aliada pedagógica: que el estudiante vea la derivada, simule la probabilidad y grafique el álgebra lineal en lugar de solo memorizar fórmulas. Buscamos un perfil matemático fuerte que use Python como laboratorio del aula.

lo que harás

  • Impartir asignaturas de matemáticas: cálculo, álgebra lineal, matemática discreta, estadística y probabilidad.
  • Integrar Python como herramienta didáctica con NumPy, SymPy, Matplotlib y notebooks Jupyter para visualizar y experimentar.
  • Diseñar prácticas donde el estudiante programa el concepto: métodos numéricos, simulaciones Monte Carlo, ajuste de curvas, series.
  • Construir material interactivo reutilizable: notebooks, mini-proyectos y retos de código con enunciado matemático.
  • Tender puentes con las cátedras de programación, ciencia de datos e inteligencia artificial.
  • Reforzar a estudiantes con dificultades usando visualización y experimentación como apoyo.

lo que buscamos

  • Título de tercer nivel en Matemáticas, Física, Ingeniería o afines con sólida base matemática.
  • Maestría afín (o en curso avanzado), valorada para la carga académica.
  • Nivel funcional de Python: no necesitas ser ingeniero de software, sí saber programar lo que enseñas.
  • Manejo —o disposición real a aprender— de NumPy, SymPy, Matplotlib y Jupyter.
  • Experiencia docente y capacidad para volver concreto lo abstracto.
  • Ganas de rediseñar cómo se enseña matemáticas, no de repetir el sílabo de siempre.

El plus metodológico que valoramos

Si ya usas notebooks, GeoGebra, Manim, R o simulaciones en tus clases —y tienes material propio para demostrarlo— cuéntanoslo en la postulación. Ese diferencial pesa tanto como la formación formal.
